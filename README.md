# Backend Dev

![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=flat-square)
![Maintained](https://img.shields.io/badge/Maintained-yes-blue?style=flat-square)


Personal backend engineering notes and code examples, organized as a learning path from fundamentals to design and system architecture, in Node.js and Java.

## Structure

```
node-backend-dev/
├── backend-with-first-principle/   # Protocols, HTTP, architecture, persistence
├── backend-with-js/                # Node.js learning path (phases 1–5, week1 exercises)
├── backend-with-java/              # Java, Spring Boot & Spring MVC
├── backend-work-anynonimus/        # Setup guides (WSL, Docker), reverse-engineering notes
└── LLD/                            # SOLID, design patterns, OOP, UML
```

| Folder | What you'll find |
|---|---|
| `backend-with-first-principle/` | Network protocols, HTTP, system architecture, data handling |
| `backend-with-js/` | Phased Node.js path; week 1 covers file I/O, REST APIs, logging, validation |
| `backend-with-java/` | Spring Boot / MVC internals, patterns, Java tooling |
| `backend-work-anynonimus/` | Dev environment setup and quick-reference guides |
| `LLD/` | SOLID (parts 1 & 2), Factory/Strategy/Observer, OOP concepts, UML |

## Tech

- **Languages:** Java, JavaScript (Node.js)
- **Frameworks:** Express.js, Spring Boot, Spring MVC
- **Data:** PostgreSQL, MongoDB, Redis
- **Messaging/Search:** RabbitMQ, Elasticsearch
- **Security/APIs:** JWT, OAuth, REST, GraphQL
- **Tools:** Docker, WSL, Git, Linux

## Suggested Path

1. `backend-with-first-principle/` – foundations
2. `backend-with-js/` **or** `backend-with-java/` – pick a language track
3. `LLD/` – design principles and patterns
4. Return to first-principles notes for system design topics

## Getting Started

```bash
git clone https://github.com/basavaraj8143/node-backend-dev.git
cd node-backend-dev
```

Then open the folder for your chosen track and follow the markdown notes in order.
